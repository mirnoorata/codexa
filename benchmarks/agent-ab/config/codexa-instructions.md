Codexa is available as repository-local context and lifecycle tooling. Use its
session context and task brief before editing. For a non-trivial change, save a
bounded change plan with explicit invariants, select targeted tests before the
edit, review the actual diff afterward, and use the proof card only as a
handoff summary. Read source and run the repository tests yourself; Codexa's
output is evidence to inspect, not a correctness verdict.
